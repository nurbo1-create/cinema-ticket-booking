# Cinema Ticket Booking

Frontend web application for browsing movies and booking cinema tickets.

## Features

- Movie catalog
- User authentication interface
- Seat selection
- Booking flow
- Payment page
- User profile
- Admin interface
- LocalStorage-based client-side data handling

## Tech Stack

- HTML
- CSS
- JavaScript
- LocalStorage

## Project Type

Academic frontend project developed as part of a team of 2.
